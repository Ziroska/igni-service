# IGNI Service

IGNI Service is the lightweight hall-operations companion to IGNI Manager.

## 1.0 Alpha 1

Focus: fast service during a shift without CRM, inventory, mixes or analytics.

Included:
- main hall and summer veranda maps;
- open/close shift;
- hookah counter per shift;
- preparation state and explicit **Deliver hookah** action;
- 22-minute coal-service timer for classic hookahs;
- 40-minute timer for electronic bowls;
- maximum 4 coal changes;
- sound alert when service is due;
- multiple hookahs per table;
- active tables panel;
- move an active table to a free table;
- persistent table renumbering;
- persistent active sessions and timers across app restarts.

Android package: `ru.igni.service`
